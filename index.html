Project Description

  • Simple BMI Calculator web application using HTML, CSS, and JavaScript
  • Accepts height and weight input in metric and imperial units
  • Calculates BMI and displays result instantly
  • Categorizes result into Underweight, Normal, Overweight, and Obese
  • Provides basic health tips based on BMI category
  • Includes navigation to switch between Calculator and About section
